# 学年別内容照合・追加確認

元計画72項目の対応表とは別に、文科省の内容概要と現在の生成形式を照合するための作業表です。単元名の一致だけで充足判定しません。

参照：文部科学省『小学校学習指導要領（平成29年告示）解説 算数編』。PDF17〜20ページの学年別概要、および位置・データの該当説明を確認。
https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf

|確認項目|現在の対応・コード確認|判定と次の作業|
|---|---|---|
|小1の形の構成・分解|e1-shapeCountの三角形ピース回転と形の数え分けを実装・実回答済み|この活動を保持。箱・筒・球など立体の見方や位置表現まで同じ問題で充足とはしない。幼児側の教材との違いも点検する|
|小2の箱の形|e2-shape_polygon2は主に平面図形。小4の展開図と小5の角柱・円柱は別学年の教材|小2向けに面の形と箱の対応を扱う問題の到達先を確認・補強する|
|小2の表・グラフ|表示49ステージに独立したデータ単元を確認できず。小1 e1-pictureDataの表、小3 e3-barDataの棒グラフは存在|小2段階の分類整理と簡単な表・図の問題を補強対象とする。前後の学年にあるだけで対応済みにはしない|

ここに挙げた未確認事項は、実装・実画面を見ずに完了へ変更しません。一方、授業全体の自由活動や考え方すべてをアプリの問題数へ換算しません。アプリで扱う問題・操作の範囲と、教師や保護者と取り組む活動を区別して記録します。

次に進める順：小2の表・図 → 小4の位置 → 小4の二次元の表 → 箱/そろばん/分布の表現の到達先点検。既存ステージ内へ適切に統合できるものは統合し、異なる単元を無理に混ぜません。
