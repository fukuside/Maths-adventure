操作・ルール

左パッドを左右スワイプで移動（指を置いている間は移動、離すと停止）／矢印キーでも移動。赤い落下予告から離れて回避！
上スワイプでジャンプ、空中でもう一度上スワイプで二段ジャンプ／スペース2回でも操作可能。道中の❤️（1個回復・3個）と、高い足場の💖（全回復・1個）や🛡️（全身シールド6秒・2個）を狙おう。ボスもジャンプ！ ショットは高さを合わせて当てよう。仲間も同じ固定スキルを使います。主人公スキルは固定（Xキー）。大剣は3振り、1振り5ダメージ（3振り・最大15）。ハート5個でスタート。💎10点／❤️50点／岩の破壊30点／クリアボーナスはレベル1で500点、以降1レベルごとに100点アップ（レベル20で2,400点）。失敗時は加算なし。道中の❤️で1個回復（上限5）。
ボスは横3段・落下・斜めを組み合わせて攻撃。予告を見てジャンプ／左右移動！
攻撃ボタン／Zキー：短押し＝💎1個、0.7秒長押し→離す＝💎3個ショット。
ボス撃破後は宝箱に変化し、自動で開きます。
ゲーム専用の背景透過画像を順次追加中。計59枚が全身透過表示（幼児9枚・小学生001〜035、038〜047、049、052、058、063、066のN。未配置分は順次制作中）。その他はカード画像の仮表示。11テーマを巡るレベル1〜20。クリアしたレベルと次のレベルを選択可能。3回失敗後は「やさしく再挑戦」（記録は別）を選べます。クリア後はモンスターを替えて最高点・ノーダメージ・宝石20個に挑戦。
合計得点は各ステージの最高得点の合計。宝箱のアイテムは次のステージ以降で使用できます。
入場時のみ学習ダイヤ5個を使います。ゲーム内宝石は学習ダイヤとは別です。
