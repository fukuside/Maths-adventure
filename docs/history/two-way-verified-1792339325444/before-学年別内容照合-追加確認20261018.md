# 学年別内容照合・追加確認

元計画72項目の対応表とは別に、文科省の内容概要と現在の生成形式を照合するための作業表です。単元名の一致だけで充足判定しません。

参照：文部科学省『小学校学習指導要領（平成29年告示）解説 算数編』。PDF17〜20ページの学年別概要、および位置・データの該当説明を確認。
https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf

ここに挙げた未確認事項は、実装・実画面を見ずに完了へ変更しません。一方、授業全体の自由活動や考え方すべてをアプリの問題数へ換算しません。アプリで扱う問題・操作の範囲と、教師や保護者と取り組む活動を区別して記録します。

次に進める順：小2の表・図は上記範囲で実装・検証済み。小4の位置も上記範囲で実装・検証済み。小4の二次元の表 → 箱/そろばん/分布の表現の到達先点検。既存ステージ内へ適切に統合できるものは統合し、異なる単元を無理に混ぜません。
