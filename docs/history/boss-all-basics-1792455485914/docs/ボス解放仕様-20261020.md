# ★2個でボス解放（2026-10-20）

ユーザー依頼を受け、小学生の全14ボスへ追加。通常10問クリア1回を既存のchallengeTrailsから★1個として数える。未クリア・途中終了は対象外。通常のレア度55/35/10、ボス24/44/32、モンスターの一様抽選は変更しない。

- 単元の通常ステージの★を合計2個集めると自動解放。同じステージ2回、異なるステージ1回ずつの両方に対応。
- 同じ単元に通常ステージがない学年まとめは、その学年の通常ステージを対象とする。
- ★は消費しない。解放したボスは繰り返し挑戦できる。他の単元では、その単元の★2個で同じように解放する。
- 既存の★もそのまま数える。過去にクリア済みのボスは再ロックしない。新しい保存キー・解放フラグは追加しない。
- 幼児は既存の5問・バリアなし・ボス選択方式を維持する。
- 未解放ボスは残りの★数と進捗を表示し選択不可。開始処理でも同じ条件を確認。
- 小学生ボスには「SR以上の獲得率アップ！ 合計76％」「SR44％・UR32％」を表示。確定排出とは表示しない。
- 通常クリアで新しくボスが解放されたときは結果画面にボス名と解放通知を表示。

## 検証範囲

全14ボスに対し、★0個ロック、★1個で残り1、同ステージ2回・別ステージ合計2回で解放、途中終了除外、同runIdの重複除外、保存再読み込み、他学年除外、過去ボスクリア保持、幼児非適用を制御テストで確認。
実画面では、既存の確認用プレイヤーで足し算ボスの0/2ロックと説明表示、通常ステージの既存★2個から学年まとめボスが解放されて入場できることを確認。新規プレイヤーを通常20問実操作して0→2にする検証は今回未実施。スマホ実機も未実施。
