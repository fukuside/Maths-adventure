# 回答形式別の確認範囲

ブラウザーで確認した代表形式と、生成・保存の検証を分けて示すための索引。各証跡の対象のみを意味し、全ステージ・全乱数・実機タッチの完了ではない。

|確認済みの代表形式|証跡|限界|
|---|---|---|
|筆算|乗算筆算10問実操作検証.json、乗算筆算低画面10問実操作検証.json、筆算/分数関連の制作記録|固定キーと青枠の代表操作。すべての筆算・全問題の物理端末完走ではない|
|単位と計器|単位入力切替実操作検証.json、容器入力-10問実検証.json、ものさし操作-cm/mm-10問実検証.json|三択→数値、0合わせ、水位の代表。自由計測や実機ジェスチャー全般とは区別|
|式・直接数値・旧分数|旧式入力-10問実検証.json、大きな数-10問実検証.json、分数旧入力/引き算入力-10問実検証.json|入力途中の採点防止など代表の確認。実機IMEと全演算の実完走ではない|
|お金・時計|お金入力-10問実検証.json、時計入力-10問実検証.json|代表の専用キー。買い物全形式や実機タッチの完走ではない|
|図形の操作|対称点操作10問実検証.json、構成操作-congruent/scale-10問実検証.json、形づくり10問実操作検証.json|対称点/頂点選択/回転。自由作図や全工作活動とは区別|
|追加した観察・図表|小1立体と位置、小2箱/データ、小4位置/二次元表/変わり方、小6ドットの各実検証JSON|小1/小2の前半には生成器の正答で進行した部分あり。各scopeに独立計数との違いを記録|
|そろばん|そろばん-3/4-10問実検証.json|珠読み/珠ボタンでの加減。前半は生成器正答。運指・億/兆等の全抽選を実回答した結果ではない|
|幼児の絵|幼児イラスト-count/sandwich/weight/zero-5問実検証.json|4代表形式各5問。幼児本人の理解度や実機タッチを確認した結果ではない|
|図鑑・足跡・保存|図鑑パートナー保存-実検証.json、中断と足跡-実検証.json、履歴集計/抽選契約の制作記録|隔離プレイヤー/関数検証。Firebase別端末、保護者メール受信は未確認|

プログラム：全234登録21,300生成描画、ID・生成器・描画器・報酬画像の存在を検証。

画面：229ステージ初問458表示の一括点検＋新設e4-changing-tableの10問を1024/390pxで確認。230ステージの初問に到達する証跡はあるが、同一バッチで230件を再実行した記録ではない。横はみ出し/実行例外の検出範囲を保持。縦方向のすべての見切れや全タッチ操作を自動保証しない。

未実施：実機タッチ、実機日本語入力、実スピーカーの音、最新版を使ったFirebase別端末引き継ぎ。必要操作は端末での最終確認-20261018.mdを参照。
