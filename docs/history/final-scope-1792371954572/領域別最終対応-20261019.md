# 学年・領域別の最終対応（2026年10月19日）

公式の学年/領域概要と、現行アプリで到達できる問題/図/操作の範囲を整理。元計画72項目の対応表、追加不足の詳細表とは別の24行の索引。各行は代表の到達先であり、公式の小項目すべて・全授業活動・全乱数の実回答の合格判定ではない。

参照：[文科省 小学校算数解説](https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf)（PDF17〜20ページ等）。今回のWeb再取得はタイムアウトしたため、過去の照合済み内容と現行コード/台帳を使用。新たに全PDFを読み直したという意味ではない。
