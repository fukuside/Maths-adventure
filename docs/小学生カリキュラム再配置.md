# 小1〜小6 カリキュラム再配置と追加教材

文部科学省「小学校学習指導要領（平成29年告示）解説 算数編」を基準に、以前のゲーム案を学年別に調整。

## 既存教材の再配置
九九8ステージ：小3→小2。時計の読み4ステージ：小2→小1。小数入門9ステージ：小4→小3。真分数の入門・同分母の加減3ステージ：小4→小3。既存の比較には同分子・異分母・同値分数が混ざるため、小4の発展として保持。同分母だけの比較問題を小3に新設。既存分数ボスは小4の復習として残す。小4には小数の位の拡張・小数×÷整数・帯分数を追加。速さは以前の小6案を修正し小5に配置。お金は生活の応用教材として小2に保持。

## 保存・報酬
既存ステージID・カードID・画像・保存キーを変更しない。再配置はレジストリで表示学年だけ調整。報酬はrewardWorldで元のカード群を参照し、九九に九九カード、時計に時計カードを維持。追加小5・小6はカード定義が未整備のため、既存小4カード群を暫定使用。063〜072の画像のみの配置を報酬登録と混同しない。10問ランダム・3バリア・宝箱・図鑑・パートナー・幼児設定を維持。

## 今後の拡充
この追加は各単元の基本問題であり、以前の案の全WORLD・全S1〜S6の完成ではない。ものさしの操作、かさmL、平行・垂直の図、四角形の分類、折れ線・帯・円グラフの描画、縮図、展開図、度数分布、複数段階の総合文章題、筆算の途中入力、音声ガイドは追加候補。図形の文章問題の数値図は模式図として扱う。別端末のFirebase引き継ぎはこの変更の検証範囲外。

## 検証結果（2026-10-12）
既存60ステージのIDを保持、24ステージの表示学年を再配置。追加78ステージについて各100セット、計7,800セットの10問生成を確認。計算20形式について10,000件の正答を、表示文の数値から独立計算して確認。全ステージの報酬カード群が空にならないことも確認。実際のstorage.jsを隔離した保存領域で動かし、既存の小学生・幼児カード、パートナー、ジェム、EXPの保存・再読み込みを確認。
実画面では小5の速さを起動し、正答後に2問目へ進むこと、小6の分数÷分数を起動することを確認。3バリア、10問、既存パートナーを維持。新しい問題の3択が縦に折り返される表示を修正し、問題枠を新教材だけ可変高さに変更。
全追加ステージの実画面・実端末での全問クリアは未確認。別端末へのクラウド引き継ぎは未確認。
