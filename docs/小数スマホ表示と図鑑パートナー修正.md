# 小数スマホ表示・図鑑パートナー修正（2026-10-27）

- 小数をみつけよう：固定高さ・クリッピングを解除し、スマホの三択を縦並びで表示。PCの横並びは維持。
- 問題画面の未設定案内：パートナーは、ずかんから選べるよ。
- 専用選択画面を廃止し、カード図鑑→カード詳細→このこをパートナーにする に統一。所有カードのみ設定可能。
- 図鑑一覧・詳細に過去のパートナーの称号、現在設定中の表示。既存partnerStudy（0回記録を含む）を引き継ぎ、レア度間で同一モンスターの称号を共有。
- 旧partner画面への遷移は図鑑へ互換表示。
