# 合体パズル本体組み込み（2026-10-28）

ごほうびゲーム一覧へモンスター合体パズルを追加。獲得済みURカードのみを主人公候補として渡す。スキルは7種類からカードごとにランダム固定し、プレイヤー別に保存する。盤面・得点・最高記録もプレイヤー別に保存。音源は軽い音量で連続ループ。既存の毎日午前0時リセット・学習2回クリア条件と入場ダイヤ5個の処理を維持。

実ゲーム画面を撮影して960×540 WebPバナーを作成。全5ゲームで、バナー・説明・ゲーム名付きの入場ボタンを枠内へまとめた。バックアップ: docs/history/merge-integration-1793198002。

検証: 本体ビルド成功、全5ゲームの入場費5個/残高不足拒否/画面・バナー実ファイル確認、盤面画像18参照確認。7スキルの必要合体数、満タン判定、4×4/5×5の雷縦ライン消去、自動テスト成功。組み込み版で獲得UR1枚の選択・ゲーム開始・画像表示・エラーなしをブラウザ確認。一覧は本体と同じ描画関数の確認ページで配置を目視確認。
