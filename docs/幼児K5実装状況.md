# 幼児K5 実装状況

K1〜K5を公開しています。幼児はバリアなし、各ステージ5問ランダム。正解10 EXP・クリア5ジェム。幼児専用カードは後日追加します。

| ステージ | 内容 |
|---|---|
| K5-S1 | 色と形が交互に並ぶきまり |
| K5-S2 | 同じ色で形が交互に並ぶきまり |
| K5-S3 | 小・中・大の並びの空欄を選ぶ |
| K5-S4 | 果物・動物・おもちゃの仲間分け |
| K5-S5 | 同じ2個と違う1個から違う物を選ぶ |
| K5-S6 | おうちへ行ける道を選ぶ |
| K5まとめ | 6形式から異なる5形式をランダムに選ぶ |

並び方は2周期の見本と空欄で、絵が小さくなりすぎない表示にしています。大きさ・仲間・違いの回答は3択横並び。道は直線・曲がり道・カーブの2択で、壁のある道と通れる道を区別します。絵を直接タップして答えます。
長さ問題の拡大・横並び、K3の生活用品イラストを維持しています。K6・音声・ヒント・カードは未実装です。保存キーと既存教材IDは変更しません。

35,000問題・7,000セットで正答、規則、仲間の一意性、違う物の一意性、まとめの配分を検証しました。DOMと保存先を模した検証で全35ステージのクリア・バリアなし・WORLDへの戻りと小学生10問・3バリアを確認しました。実ブラウザー表示と実クラウド保存は未確認です。
