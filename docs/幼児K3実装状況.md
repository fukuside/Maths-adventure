# 幼児K3：生活用品イラスト版

図形だけの表示から、生活用品のイラストで形を探す問題へ変更しました。

| 形 | 登場するもの |
|---|---|
| 丸 | お皿・時計・クッキー |
| 三角 | おにぎり・サンドイッチ・ピザ |
| 四角（正方形） | ハンカチ・窓・クラッカー |

同じ形の問題では、見本と答えに別の生活用品を使います。仲間分けでも、見本2つと答えを違う物にします。輪郭が明確な正面のイラストを使い、角度・影によって形が曖昧にならないようにしました。
組み合わせは、三角のサンドイッチ2つを合わせて四角いパンになる配置を選びます。輪郭とパンの断面で生活場面に結び付けています。
短いひらがなの名前も添えていますが、文字を読まなくても絵を直接タップして回答できます。

K3は6ステージ＋まとめ、各5問ランダム、バリアなし。正解10 EXP・クリア5ジェムを維持します。幼児専用カードは後日追加します。

21,000問題・4,200セットの検証で、形と生活用品の対応、見本と正解が異なる物であること、全21ステージの回答・クリア、小学生10問・3バリアの維持を確認しました。実ブラウザー表示と実クラウド保存は未確認です。
