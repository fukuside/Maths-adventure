# 幼児K4 実装状況

K1〜K4を公開しています。幼児はバリアなし、各ステージ5問ランダム。正解10 EXP・クリア5ジェム。幼児専用カードは後日追加します。

| ステージ | 内容 |
|---|---|
| K4-S1 | 大きいお皿を選ぶ |
| K4-S2 | 長い鉛筆を選ぶ |
| K4-S3 | 高い積み木を選ぶ |
| K4-S4 | 天びんの下がった側の重い物を選ぶ |
| K4-S5 | りんごの多い・少ないを選ぶ |
| K4-S6 | 見本と同じ長さの鉛筆を選ぶ |
| K4まとめ | 上の6形式から異なる5形式をランダムに選ぶ |

通常は2択、同じ長さは3択。左端・床・太さなど比較の基準をそろえています。重さの問題は「重いほうが下がる」という説明と天びんを表示し、物の大きさだけで重さを決めません。個数は1〜10、差は2個以上です。短いひらがなの説明と生活用品のSVGイラストを使い、直接タップで回答します。

K5〜K6・幼児カード・音声・段階的ヒントは未実装です。保存キー・既存教材ID・保存処理は維持しています。

## 検証

K1〜K4合計28,000問題・5,600セットで正答、個数、天びんの位置、まとめの形式配分を確認しました。DOMと保存先を模した検証で全28ステージのクリア、バリアなしの再挑戦、WORLDへの戻り、学習レポート名、小学生10問と3バリアを確認しています。実ブラウザー表示と実Firebaseへの保存・引き継ぎは未確認です。
