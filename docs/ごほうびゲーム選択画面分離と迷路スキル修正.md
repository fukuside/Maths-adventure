# ごほうびゲームの選択画面分離・迷路スキル修正（2026-10-28）

対象：迷路、ピンボール、宝釣り。本体の既存3ゲームを修正。合体パズルは未統合のまま。

- 最初は所持カードのモンスター選択、特性・スキル説明、遊び方のみ。ゲームスタートで選択UIを隠し盤面を表示。
- 迷路・宝釣りは所持N、ピンボールは所持SRを継続。入場費・学習記録・保存キー・音声設定は変更しない。
- 迷路の画像は明示サイズと絶対配置で表示し、透過画像を取得できない場合はカード原本画像へフォールバック。カード原本変更なし。
- 迷路のスキルを「みちつなぎ（1マス正解向き）」「みちしるべ（1マス強調）」「まきもどし（最後の1回転を戻す。履歴がなければ1マスつなぐ）」に変更。どれもステージ1から使用可能、1ステージ1回、カットイン後に効果。
- 石はミッション用として独立。既存の仲間集め・敵・ステージ・続きから再開を保持。回転履歴を既存保存データの追加フィールドとして保存。
- 選択画面では敵の時計やピンボールの進行を停止。宝釣りは浮きを投げるまで60秒の計測を始めない。
- 共通UI：public/reward-games/reward-lobby.js / reward-lobby.css。

検証：390×844のブラウザーで選択画面・盤面のモンスター画像読み込みと寸法、3ゲームの開始操作、迷路スキルのステージ1発動、選択画面への戻りを確認。迷路3スキルと使用済み・回転履歴の保存復元、25ステージの生成経路を自動検証。Viteビルド成功。iPhone/iPad実機のSafari確認・公開は未実施。
