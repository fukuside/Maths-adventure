# 文科省算数解説との部分照合：小6データ（2026-10-15）

参照：[文部科学省・小学校学習指導要領（平成29年告示）解説 算数編](https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf)。古い参照URLは取得タイムアウト、新URLの本文取得を確認。今回は小6データ分野だけの部分照合で、全学年照合完了ではない。

小6では、代表値の算出に加えて、階級ごとの人数を整理する表、柱状グラフ、分布の特徴や結論の妥当性を考える活動が必要。本文の冊子308頁付近と320〜321頁の例を参照。

|確認対象|現在の実装|残作業|
|---|---|---|
|中央値|5件/6件の記録、偶数件数は中央2値の平均を数値入力|分布比較や文脈に沿った解釈|
|最頻値|記録ごとの人数表から最多の記録を数値入力|複数の最多値や該当なし等を扱う際の出題設計|
|度数分布表|単一の値ごとの人数表まで|以上・未満の階級で集計し、境界値も扱う教材|
|柱状グラフ|未実装|階級の横幅と人数の高さを示す図、表との対応|
|比較・説明|代表値の単発計算中心|平均だけで結論を出さず分布も確かめる問い|
|作成操作|未実装|データを階級に振り分けたりグラフを作る操作|

次の実装は、階級の境界で重複計数しない度数分布表と柱状グラフを優先する。単一値の人数表を実装したことだけで、度数分布全体の完了とは扱わない。

今回の照合ではアプリのステージ・カード数、保存仕様、抽選仕様は変更していない。ユーザー指定の水量比較の移し替えヒント、広さ比較の2次元図、共通の案内文重複修正を保持する。
