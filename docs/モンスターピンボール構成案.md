# モンスターピンボール 初期構成

お宝釣りの次に制作するゲーム。まず独立プレビューで遊び心地を確認し、承認後に既存ごほうび一覧へ接続する。未公開。

## １プレイの流れ
所持カードから主人公選択 → 大きな発射ボタンを押してボール発射 → 左右のフリッパーで打ち返す → ターゲットを壊して宝箱解放 → 全３球終了後に得点・最高記録と集合演出。

## 操作と画面
スマホ縦を基本に台全体を画面内へ。画面左下・右下を大きくタップして各フリッパーを動かす。PCは左右矢印。初球は発射方向をガイドし、落球後は自動で次球待機。フリッパーは押している間上がり、離すと戻る。２本指同時入力に対応。文字説明より指マークと短い動く見本。

## 面白さの核
ボールが当たると敵モンスターが驚く。連続ヒットでコンボと音程が上がる。３個の宝石スイッチを点灯すると宝箱出現。宝箱に当てるとコインが舞う。繰り返し同じバンパーだけで稼ぐ行動には連打得点上限を設け、台全体を使う方がお得。

## 台と難しさ
最初は森林の宝箱台１つ。バンパー３個、宝石スイッチ３個、上部宝箱、左右安全レーン。最初の５秒はボールセーブ。３球の間に少しずつ速度が上がるが上限あり。台の外へ瞬間移動する球や即落球の配置を避け、物理計算を時間基準で行う。将来は海底・空・お城へ台を増やす。

## カードと報酬（提案・初期値）
主人公カードの顔をボール内に表示、透過絵を台の応援役に配置。カードごとに固定の小さな特性（球が少しゆっくり／セーブ時間延長／コンボ猶予延長など）。レア度制限と入場費は試遊後に決定。プレビューは無料、学習ダイヤ・星・所持カードには触れない。ゲーム内コインは学習ダイヤと分離。

## 点数の初期案
バンパー100、宝石スイッチ150、３点灯で500、宝箱1000。コンボは最大２倍。３球通算と自己最高をプレイヤー別の新規保存キーへ。失敗でも獲得点を表示。終了は主人公がジャンプし、台の宝箱とコインが弾ける。

## 制作と検証
最初に１台の物理・左右同時タッチ・球セーブ・３球終了・再挑戦を実装。端末サイズによる球速差、衝突すり抜け、画面外落ち、タスクバーへの誤タッチを確認。その後に絵・音・コンボ・カード選択を加える。実機確認を未実施のまま成功扱いしない。
