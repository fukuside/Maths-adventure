# 長さの比較：見た目のバリエーション

K4-S2（長いほう）とK4-S6（同じ長さ）、まとめの該当問題を更新しました。
横・縦・右上がり・右下がりの4方向と、鉛筆・クレヨン・リボン・歯ブラシの4用品をランダムに組み合わせます。色と長さ、正解位置も変化します。
1問の中では用品・向き・色・縮尺・基準位置をそろえ、長さを比べる情報が一意に決まるようにしています。異なる問題では向きと用品が変わります。5問の各セットに全方向が必ず出る仕様ではありません。
回転は同じ正方形の表示範囲内で行い、斜めだけ小さく表示したり、切れて見えたりしないようにしています。
バリアなし・5問ランダム・報酬と保存処理は維持します。

28,000問・5,600セットで判定・クリアと小学生の既存動作を確認し、16種類の用品と向き、共通縮尺、回転後の表示範囲を検証しました。実ブラウザー表示は未確認です。
