# 幼児カード画像：使用した制作仕様

ImageGenの標準ツールで生成。既存001プラスラビットNを塗りの参考とし、各キャラクターのNをSR、NとSRをURの個体参照に使用しています。出力は元画像を保存し、承認されたサイズ調整で1080×1080 PNGへ統一します。

## 共通プロンプト

One standalone square PNG game monster illustration, ideally1080×1080. Match the polished Japanese fantasy mobile game painting of the provided style reference, with soft luminous shading, expressive eyes and appealing character proportions. Full-body character centered. Fit the complete silhouette, including ears, wings, feet, tail, cape and staff, in the central60–65% of both width and height. At least18% quiet background margin on each edge. Background fills the canvas. No text, digits, runes, labels, mathematical marks, card borders or frames. N is cute, SR is brave and UR is mythically majestic. Preserve the same individual, face, palette and signature features between stages.

生成で余白が不足した画像には、同じ画像を参照して「個体・装備・塗りを保ち、カメラを引いて全身を中央65%に収める」という構図修正を行っています。これは画像生成での修正であり、後処理でキャラクターを切り抜いたり背景を差し替えたりしていません。
