# K5：4グループ・24種類とコの字型の道

| グループ | イラスト |
|---|---|
| おもちゃ | ボール・ブリキロボット・人形・積み木・凧・こま |
| 動物 | 猫・犬・うさぎ・象・ライオン・ペンギン |
| 果物 | りんご・バナナ・梨・みかん・ぶどう・いちご |
| のりもの | 車・舟・三輪車・飛行機・バス・電車 |

車をおもちゃからのりものへ移し、グループ間の重複をなくしています。仲間分けは、指定されたグループの異なる見本2つをランダムに選び、同じグループの別の1つと、他の2グループから1つずつを回答の3択にします。4グループから出題しますが、選択肢を4択に増やすことはありません。
「違うもの」でも増えた24種類を使います。生活用品・乗り物は正面や側面のイラストで、形や用途が分かるようにしています。

道選びは9種類・正誤合わせて18枚の地図。追加のコの字型は、猫から右へ進み、縦の道を通って左側の家へ戻る経路です。通れる地図は途中の川に橋があり、通れない地図は草地で道が途切れています。上下を反転したコの字も用意しました。終端をT字にしただけの違いではなく、途中の道・川をたどる問題です。

35,000問・7,000セットで、24種類の描画、グループの重複なし、見本2個・回答3択・正解1個、18地図の到達、全35ステージと小学生の既存動作を模擬環境で検証しました。実ブラウザー表示と実クラウド保存は未確認です。
