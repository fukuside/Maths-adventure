# 基礎を一巡してボス解放（2026-10-20 最新承認）

- 同単元の表示対象の通常ステージをすべて最低1回、10問クリアして★1個ずつ獲得する。
- その上で追加の★1個が必要。合計必要数は対象ステージ数＋1。追加分は好きな対象通常ステージで獲得でき、基礎一巡前の繰り返し分も数える。
- 同じステージを何度繰り返しても、未クリアの通常ステージがあれば解放しない。
- 学年まとめボスは同学年の表示対象の通常ステージすべてを対象とする。
- 既存★を利用。★は消費しない。過去にクリア済みのボスは再ロックしない。幼児は従来どおり。
- 未解放表示は「基礎クリア X/Y」「追加の★ X/1」と次の取り組みを案内。SR以上76％（SR44％・UR32％）の説明を維持。
- 通常・幼児55/35/10、ボス24/44/32の抽選、既存保存キー・カード・履歴は変更なし。
