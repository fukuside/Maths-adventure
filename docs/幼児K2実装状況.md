# 幼児K2 実装状況

幼児モードはバリアなし。通常・まとめとも毎回5問ランダム。正解で10 EXP、クリアで5ジェム。カードは幼児専用カードを後日追加し、小学生カードを流用しません。この方針は利用者確認済みです。

K1とK2を公開しています。K3〜K6は準備中です。

| ステージ | 内容 | 回答 |
|---|---|---|
| K2-S1 | 6〜10を数える | 数字3択 |
| K2-S2 | 1〜10の同じ数字を選ぶ | 数字3択 |
| K2-S3 | 6〜10の数字と個数を合わせる | 個数の絵3択 |
| K2-S4 | 1〜9個から1個増える | 結果の個数の絵3択 |
| K2-S5 | 2〜10個から1個減る | 結果の個数の絵3択 |
| K2-S6 | 1〜9の次の数 | 数字3択 |
| K2まとめ | 6形式から異なる5形式をランダムに選ぶ | 3択 |

絵は5個区切りの2列表示。増える問題は元の個数と追加の1個を残して表示し、減る問題は対象の1個へ×印を重ねて示します。0と10を超える数は扱いません。読み上げ・ヒントは未実装です。

## 確認

K1とK2の合計14,000問題・2,800セットで、正答・候補・個数・まとめの形式配分を確認しました。DOMと保存先を模した検証で全14ステージのクリア、バリアなしの再挑戦、K2への戻り、学習レポート名、小学生の10問と3バリアの維持を確認しています。
実ブラウザー表示・実Firebaseへの保存と引き継ぎは未確認です。既存の保存キー・保存処理・教材IDは変更していません。
