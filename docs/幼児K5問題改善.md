# K5 仲間分け・道選びの改善

仲間分けは「くだもの／どうぶつ／おもちゃを もうひとつ えらんでね」と問いかけます。見本2つを箱に入れ、分類名と空欄を表示し、下の3択から同じ仲間を追加します。動物に見えるぬいぐるみを誤答にせず、おもちゃにはボール・車・凧を使います。

道選びは直線・曲がり道・カーブ・川・川の曲がり道・上方向の迷路・下方向の迷路の7種類。川は橋がある道とない道、迷路は分岐と行き止まりを設けています。猫から家へ道の上だけをたどる問題です。
1問では2枚の地図から到達できる1枚を選びます。自由な経路描画や移動操作はまだ使いません。7種類それぞれに通れる地図と通れない地図を用意し、道の接続データと描画が対応する設計です。

通常・まとめとも5問ランダム、バリアなし、報酬・保存処理・既存ステージIDを維持しています。
35,000問・7,000セットと14枚の地図について、正答一意性、橋、分岐、行き止まり、家への到達を検証しました。全35ステージと小学生の既存動作も模擬環境で確認しています。実ブラウザー表示・実クラウド保存は未確認です。
