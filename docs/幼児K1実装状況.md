# 幼児K1 実装状況

K1の通常6ステージ＋まとめを実装済みです。幼児は通常・まとめとも毎回5問ランダム。小学生は既存の10問ランダムを維持します。

| ステージ | 内容 | 回答 |
|---|---|---|
| S1 | 同じものを選ぶ | 絵2択 |
| S2 | 1〜3を数える | 数字2択 |
| S3 | 1〜5を数える | 数字3択 |
| S4 | 数字と個数を合わせる | 個数の絵3択 |
| S5 | 多いほうを選ぶ | 個数の絵2択 |
| S6 | 少ないほうを選ぶ | 個数の絵2択 |
| まとめ | 上の6形式から異なる5形式をランダムに選ぶ | 形式に応じ2〜3択 |

比較は同じ大きさ・間隔の絵を左端からそろえて並べ、個数差を2個以上にしています。正解の位置もランダムです。
直接タップして回答し、誤答でもバリアを減らさず再挑戦できます。正答で10 EXP、5問クリアで5ジェム。幼児カードは未作成のため抽選しません。
K2〜K6は準備中です。ヒント・音声・クリア済み一覧の保存は未実装。既存の保存キー・カード・教材IDは維持しています。学習レポートには幼児まとめを「かずと なかよし：まとめ」と記録します。

## 検証

7,000問題・1,400セットで、5問生成、正答、選択肢の一意性、表示の個数、比較の差、まとめの5形式配分を確認しました。DOM・保存先を模した検証で、全ステージのクリア、二重回答防止、報酬、まとめのレポート名、小学生10問・3バリアを確認しています。
実ブラウザー表示と実Firebaseの保存・引き継ぎは未確認です。
