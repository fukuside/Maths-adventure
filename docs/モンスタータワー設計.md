# モンスタータワー 構成案

迷路に続く次のごほうびゲーム。現在は設計・試遊段階。本体へはまだ追加しない。

## 遊びの核
左右に動く足場をタップで落とし、高い塔を積み上げる。主人公は所持URカードを選択する構成案。足場に乗って空へ登り、5階ごとの宝箱で達成感をつくる。

## 操作と難易度
画面タップまたは「おとす」1操作。重なった部分が次の足場になる。ぴったりなら幅を維持して連続ボーナス。ずれると幅が狭まり、外れると終了。速度は階数で段階的に上げ、上限を設ける。急な高速化を避ける。5階ごとの宝箱で幅を少し回復する。

## ごほうびと演出
通常着地80点、ぴったり150点＋連続加点、5階ごとの宝箱500点を試遊の仮値とする。地上→雲→星空と5階ごとに変化。カメラは主人公と最上段を追う。終了時は到達階・自己最高・前回との差を表示し、記録更新をお祝いする。釣り・ピンボールと報酬効率を比較してから本体の換算を決定する。

## スキル案
最初の試遊は「時のスローモーション」1種類。成功でゲージがたまり、発動時に主人公カットイン、6秒間足場をゆっくり動かす。今後は幅回復、1回救済、ぴったり判定補助を比較する。同時採用せず操作性の確認を先に行う。

## 保存・実装の境界
最高到達階とハイスコアをプレイヤー別に保存する。本体の学習・カード・音設定・入場処理を共通化して使い、専用キーを分離する。試遊版の仮キャラ・仮保存を本体へ流用しない。UR限定は構成案で、利用機会を確認して確定する。
